## 🎯 About

This is my personal portfolio website built with pure HTML, CSS, and JavaScript. It features a clean, professional design with smooth animations and a fully responsive layout.

## ✨ Features

- 🎨 Clean and modern design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Smooth scrolling navigation
- 🎭 Animated section reveals
- 🔝 Back to top button
- 💫 Hover effects and transitions
- 🌙 Dark theme with blue accents
- 📊 Project showcase with live links
- 📧 Contact information and social links

## 🛠️ Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling and animations
- **JavaScript (Vanilla)** - Interactivity and animations

No frameworks or libraries required!

## 🚀 Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/AdityaAdlak/portfolio.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd portfolio
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   # Or use Live Server extension in VS Code
   ```

That's it! No installation or build process needed.

## 🎨 Customization

To customize this portfolio for yourself:

1. **Update Personal Information**
   - Open `index.html`
   - Replace name, title, contact details
   - Update education, skills, and projects

2. **Change Colors**
   - Open `style.css`
   - Modify the blue color (#4a90e2) to your preferred color
   - Adjust background colors if needed

3. **Add/Remove Sections**
   - Edit `index.html` to add/remove sections
   - Update navigation links in both HTML and CSS

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px

## 🌟 Features Breakdown

### Smooth Scrolling
Click any navigation link to smoothly scroll to that section.

### Scroll Reveal Animation
Sections and cards animate into view as you scroll down the page.

### Active Navigation
Navigation highlights the current section you're viewing.

### Back to Top Button
Appears when you scroll down, click to return to the top.
